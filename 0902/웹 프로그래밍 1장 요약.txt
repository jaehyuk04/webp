1. 웹의 기본 개념
    
    웹의 목적: 여러 컴퓨터에서 문서(웹 문서)를 공유하고 보는 것
    
    웹의 구조: 인터넷을 활용해 거미줄처럼 연결된 정보 소통망(wwd: world wide web)
    
    구성요소
    
    1)웹서버:  웹 사이트를 담고 있는 컴퓨터(문서/이미지, 동영상, 클라이언트 요청, html…. 등)
    
    2)웹 클라이언트: 사용자 인터페이스(브라우저로 문서 요청 및 출력)
    

1. 인터넷 vs 웹
    
    인터넷: 컴퓨터 연결 네트워크, ip 주소로 컴퓨터 구분함
    
    웹: 인터넷을 활용하는 여러 응용 서비스(이메일, 메신져, 인터넷 전화기….등)
    
    #인터넷 = 고속도로, 웹 = 물류산업(인터넷 기반)
    

1. 웹 문서 vs 전자 문서
    
    저장방식
    
    웹 문서: 페이지별로 파일 분할, 하이퍼링크로 연결
    
    전자 문서: 하나의 파일에 모든 내용 저장
    
    읽는 순서 
    
    웹 문서: 사용자가 하이퍼 링크로 선택
    
    전자 문서: 작성자가 결정
    

1. url 구조
    
    http://(프로토콜)www.oracle. com(서버주소):80(포트)/technetwork/java(경로명)/indexhtml(파일이름)
    
2. 웹을 선호하는 이유
    
    배우기 쉬운 html 태그
    
    효율적인 http 통신(서버 부담 down)
    
    서버-클라이언트 작업 분담
    
3. 웹 페이지 구성 3요소
    
    html(대표 틀), css(디자인), javascript(상호작용)
    
4. html5의 기능과 의의
    
    기능: 웹 폼, 오디오/비디오, 캔버스, SVG, 웹 스토리지, 웹 SQL DB, 파일 입출력, 위치 정보 API, 웹 워커, 웹 소켓, 오프라인 웹 앱
    
    의의: 플랫폼/기기 의존성 제거, Active-X·플러그인 불필요, 문서 작성을 넘어 웹 애플리케이션 개발 지원
